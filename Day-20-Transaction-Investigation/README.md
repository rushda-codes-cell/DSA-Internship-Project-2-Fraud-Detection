# Day 20 – Transaction-Level Fraud Investigation

## Objective

To investigate individual suspicious transactions using model
predictions, risk scores and explanations.

## Work Completed

- Selected individual transactions.
- Displayed transaction information.
- Generated fraud prediction.
- Generated risk score.
- Assigned risk category.
- Identified important features.
- Generated SHAP explanation.

## Outcome

A transaction-level investigation workflow was developed.
