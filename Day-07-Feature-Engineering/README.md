# Day 07 – Feature Engineering & Fraud Indicators

## Objective

To create meaningful features that improve the ability of machine
learning models to identify suspicious transactions.

## Work Completed

- Created transaction-based features.
- Created frequency-based indicators.
- Created temporal indicators.
- Created behavioural indicators.
- Evaluated engineered features.
- Prepared the final feature set.

## Outcome

A feature-engineered dataset was prepared for machine learning.
