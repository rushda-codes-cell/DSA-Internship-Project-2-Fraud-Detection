# Day 08 – Train, Validation & Test Strategy

## Objective

To create reliable training, validation, and testing datasets while
preventing data leakage.

## Work Completed

- Created training dataset.
- Created validation dataset.
- Created testing dataset.
- Applied stratification where required.
- Verified class distributions.
- Prevented data leakage.
- Recorded final dataset shapes.

## Outcome

A reliable data splitting strategy was established for model training
and evaluation.
