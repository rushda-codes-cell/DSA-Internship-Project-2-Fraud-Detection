# Day 16 – Autoencoder-Based Anomaly Detection

## Objective

To detect anomalous transactions using an Autoencoder.

## Work Completed

- Designed Autoencoder architecture.
- Prepared training data.
- Trained the Autoencoder.
- Calculated reconstruction error.
- Analyzed reconstruction error distribution.
- Selected anomaly threshold.
- Identified anomalous transactions.

## Outcome

An Autoencoder-based anomaly detection approach was developed.
