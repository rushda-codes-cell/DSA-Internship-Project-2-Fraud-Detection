# Day 09 – Class Imbalance Handling

## Objective

To address the imbalance between fraudulent and legitimate transactions.

## Work Completed

- Analyzed class distribution.
- Calculated fraud and non-fraud proportions.
- Studied the impact of class imbalance.
- Selected an appropriate imbalance-handling technique.
- Applied the technique to the training data.
- Compared class distribution before and after treatment.

## Outcome

The class imbalance problem was addressed to improve fraud detection.
