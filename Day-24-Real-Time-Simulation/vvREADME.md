# Day 24 – Real-Time Transaction Streaming Simulation

## Objective

To simulate real-time transaction processing for fraud detection.

## Work Completed

- Created transaction stream.
- Simulated incoming transactions.
- Applied preprocessing.
- Generated real-time predictions.
- Generated risk scores.
- Tested transaction-by-transaction processing.

## Workflow

Transaction
→ Preprocessing
→ Feature Engineering
→ Fraud Detection
→ Risk Score
→ Decision

## Outcome

A real-time transaction processing simulation was developed.
