# Day 06 – Temporal & Behavioural Fraud Analysis

## Objective

To identify temporal and behavioural patterns associated with
fraudulent activity.

## Work Completed

- Analyzed transaction timing.
- Studied transaction frequency.
- Analyzed transaction behaviour.
- Investigated unusual activity patterns.
- Compared fraud and legitimate behaviour.
- Identified potential behavioural fraud indicators.

## Outcome

Temporal and behavioural patterns were identified for use in
feature engineering.
