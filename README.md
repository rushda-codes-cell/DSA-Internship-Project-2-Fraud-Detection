# Intelligent Fraud Detection & Real-Time Risk Monitoring System

## Project Overview

This project is developed as Project 2 of the Data Science & Analytics Internship. The objective is to develop an intelligent fraud detection system capable of identifying fraudulent and suspicious transactions using machine learning, anomaly detection, explainable AI, real-time streaming, automated alerts, and an interactive dashboard.

The project follows a 30-day development workflow, beginning with dataset collection and preprocessing and progressing through machine learning, anomaly detection, hybrid risk scoring, explainability, real-time streaming, alert generation, dashboard development, and final system integration.

## Objectives

- Detect fraudulent transactions using machine learning.
- Analyze suspicious transaction behaviour.
- Handle class imbalance.
- Compare multiple machine learning models.
- Detect unknown anomalies.
- Generate a hybrid fraud risk score.
- Explain model predictions using SHAP.
- Implement real-time transaction processing.
- Generate automated fraud alerts.
- Build an interactive Streamlit dashboard.
- Develop an end-to-end fraud monitoring system.
