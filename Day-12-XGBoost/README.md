# Day 12 – XGBoost Fraud Detection

## Objective

To implement XGBoost as an advanced supervised machine learning model
for fraud detection.

## Work Completed

- Configured XGBoost.
- Trained the model.
- Generated predictions.
- Evaluated model performance.
- Generated confusion matrix.
- Calculated precision, recall and F1-score.
- Calculated ROC-AUC.
- Analyzed feature importance.
- Compared XGBoost with previous models.

## Outcome

An XGBoost-based fraud detection model was successfully developed.
