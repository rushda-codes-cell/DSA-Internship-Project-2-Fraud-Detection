# Day 02 – Dataset Collection & Data Audit

## Objective

To collect the selected fraud detection dataset and understand its
structure and data quality.

## Work Completed

- Loaded the dataset.
- Checked dataset dimensions.
- Examined column names and data types.
- Checked missing values.
- Checked duplicate records.
- Analyzed the target variable.
- Studied fraud and legitimate transaction distribution.
- Generated basic statistical summaries.

## Outcome

The initial structure and quality of the dataset were analyzed and
potential data quality issues were identified.
