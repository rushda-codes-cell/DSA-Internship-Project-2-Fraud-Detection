# Day 25 – Kafka Producer-Consumer Pipeline

## Objective

To implement a Kafka-based streaming pipeline for real-time
transaction processing.

## Architecture

Producer
↓
Kafka Topic
↓
Consumer
↓
Fraud Detection Model

## Work Completed

- Configured Kafka.
- Created producer.
- Created Kafka topic.
- Created consumer.
- Sent transaction data.
- Received transaction data.
- Connected Kafka streaming with fraud detection.

## Outcome

A producer-consumer Kafka pipeline was implemented.
