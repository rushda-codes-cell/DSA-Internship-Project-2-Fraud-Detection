# Day 04 – Data Cleaning & Preprocessing

## Objective

To clean and transform the raw dataset into a suitable format for
machine learning.

## Work Completed

- Handled missing values.
- Checked duplicate records.
- Corrected data types.
- Investigated invalid values.
- Investigated outliers.
- Encoded categorical variables where required.
- Applied feature scaling where required.
- Validated the cleaned dataset.

## Outcome

A cleaned and preprocessed dataset was prepared for analysis and
machine learning.
